## 0. 준비

- [ ] 처음 켜면 최상위 노트 "Nodt 사용법", "예제 1: 이번 주 할 일", "예제 2: 독서 기록"이 보인다. "시작하기"와 "연습장"만 펼쳐져 있고 "링크와 새 노트"는 최소화, 예제 둘도 최소화돼 있다. 🤖
- [ ] 예제를 복원하면 하위 노트가 몇 단계 펼쳐진 모습이 나온다. 👀
  - 지금 쓰는 `문서\Nodt`에는 예전 안내 노트가 이미 있어서 사용법 노트가 안 보인다. 아래 초기화 버튼으로 보면 된다.
- [ ] 사용법 노트의 문구와 파트 나눔이 괜찮다. 👀
- [ ] 사용법 노트가 처음 화면에서 잘리지 않는다. 창을 작게 해 두고 "사용법 노트로" 초기화해도 창이 커지며 다 보인다. 🤖
- [ ] 앱을 열 때 패널이 왼쪽부터 하나씩 나타난다. 👀
- [ ] 상단바의 초기화 버튼(설정 왼쪽) → 확인 창이 뜬다. `Esc`나 [취소]면 아무 일도 없다. 🤖
- [ ] 확인 창에 "완전 초기화"가 위에 있고 기본으로 골라져 있다. 🤖
- [ ] "완전 초기화" → 빈 화면에 "Ctrl+N 으로 새 노트" 안내. 설정은 그대로다. 다시 켜도 빈 화면이다. 🤖
- [ ] "사용법 노트로" → 사용법 노트로 돌아가고, 설정은 그대로다. 🤖
- [ ] 초기화 뒤 `문서\Nodt\backups\reset\`에 지우기 전 노트가 남아 있다. 👀
- [ ] 노트는 `문서\Nodt\notes\`에 md 파일로 저장된다. 탐색기에서 열어 본다. 👀
- 설정까지 처음 상태로 돌리려면: 앱을 끄고 `문서\Nodt` 폴더와 `%APPDATA%\app.nodt.desktop\config.json`을 지운다.

## 1. 글쓰기 (에디터)

- [ ] 본문을 눌러 바로 글을 쓸 수 있다. 🤖
- [ ] **한글 입력**이 자연스럽다. 조합 중인 글자가 깨지거나 두 번 들어가지 않는다. 👀
- [ ] 제목에서 한글을 치다가 `Enter`를 누르면, 마지막 글자까지 들어간 뒤 본문으로 내려간다. 👀
- [ ] `## ` + 공백 → 부제목, `- ` + 공백 → 글머리 목록, `[ ] ` + 공백 → 체크 목록. 🤖
- [ ] `Ctrl+B` 굵게, `Ctrl+Shift+S` 취소선. `Ctrl+I`(기울임)는 아무 일도 없다. 🤖
- [ ] 목록에서 `Tab` 들여쓰기, `Shift+Tab` 내어쓰기. 목록 밖에서 `Tab`을 눌러도 초점이 사라지지 않는다. 🤖
- [ ] 체크박스를 누르면 체크되고 글이 옅어진다. 👀
- [ ] 빈 줄에 "내용 · / 로 명령" 자리표시 글이 옅게 보인다. 👀
- [ ] 다른 곳(웹, 메모장)에서 서식 있는 글을 붙이면 굵게·목록만 남고 기울임·표·이미지는 빠진다. 👀

## 2. 링크와 새 노트

- [ ] 글 끝에서 `Ctrl+N` → 한 칸 띄우고 링크가 생긴다. 옆 컬럼에 빈 노트가 열리고 커서가 그 제목에 있다. 🤖
- [ ] 앱 창에서 `Ctrl+N`, `Ctrl+W`를 눌러도 새 창이 뜨거나 앱이 닫히지 않는다. 👀
- [ ] 제목에 커서가 있을 때 `Ctrl+N` → 본문 끝 새 줄에 링크가 생긴다. 본문이 목록으로 끝나면 목록 항목이 하나 늘어난다. 🤖
- [ ] 빈 곳을 누르면 선택이 풀린다(강조 테두리 없음). 이때 `Ctrl+N` → 첫 컬럼 맨 아래에 새 최상위 노트. 🤖
- [ ] 최상위 노트를 여러 개 만들고 끌기나 `Alt+Shift+↑/↓`로 순서를 바꾼다. 다시 켜도 순서가 남는다. 🤖
- [ ] 최상위 노트도 우클릭 → 노트 삭제 → 되돌리기로 제자리에 돌아온다. 🤖
- [ ] `Ctrl+W`: 일반 패널은 닫힘, 최상위 노트는 최소화(다시 누르면 복원). 🤖
- [ ] 새 노트를 만들고 아무것도 안 쓴 채 `Esc`나 `Ctrl+W` → 노트와 링크가 흔적 없이 사라진다(최상위 노트도). 🤖
- [ ] `Shift+방향키`나 끌기로 글을 선택하면 그 안의 링크 칩에도 선택 배경이 칠해진다. 👀
- [ ] 제목을 한 번 누르면 패널만 선택되고, 제목을 잡고 끌면 순서가 바뀐다. 두 번 눌러야 제목에 커서가 간다(제목 끝). 🤖
- [ ] 제목을 쓰고 `Enter`(또는 `Tab`, `↓`) → 본문으로. 본문 첫 줄에서 `↑` → 제목으로. 🤖
- [ ] 줄 맨 앞이나 공백 뒤에서 `/` → 메뉴가 커서 아래에 뜬다. 🤖
  - [ ] 항목: 새 노트 링크, 부제목, 글머리 목록, 체크 목록, 이 노트 삭제.
  - [ ] 글자를 더 치면 걸러진다(예: `/체`). 방향키로 고르고 `Enter`로 실행한다.
  - [ ] `Esc`나 맞는 항목이 없으면 그냥 `/` 글자로 남는다. 패널은 닫히지 않는다.
  - [ ] 단어 중간(`a/b`)에서는 메뉴가 뜨지 않는다. 👀
- [ ] 링크 칩(`>`)을 누르면 열리고(`<`로 바뀜), 다시 누르면 닫힌다. 🤖
- [ ] 커서를 링크 바로 뒤에 두고 `Ctrl+Enter` → 열기/닫기. 🤖
- [ ] 링크가 글 사이, 목록 안, 체크 항목 안 어디에 있어도 잘 동작한다. 👀

## 3. 삭제와 되돌리기

- [ ] 본문에서 링크 기호를 `Backspace`로 지우면, 그 노트와 하위 노트가 사라지고 아래에 "‘제목’ 삭제됨 · 하위 노트 N개 포함 [되돌리기]" 알림이 뜬다. 🤖
- [ ] 알림이 떠 있는 동안 `Ctrl+Z` → 노트, 하위 노트, 열려 있던 패널까지 그대로 돌아온다. 🤖
- [ ] 지운 뒤 다른 글을 조금 쓰고 알림의 [되돌리기]를 눌러도, 쓴 글은 남고 링크가 원래 자리에 돌아온다. 🤖
- [ ] 링크를 다른 글과 함께 드래그로 선택해 지워도 같은 알림이 뜬다. 👀
- [ ] 패널 상단바 우클릭 → [노트 삭제]도 같은 알림이 뜬다. 🤖
- [ ] 알림이 사라진(8초) 뒤에는 되돌릴 수 없고, 파일도 지워진다. 🤖
- [ ] 알림이 떠 있는 채로 앱을 닫으면 그때 파일이 지워진다. 🤖

## 4. 깨진 링크

- [ ] 깨진 링크는 빨간 원 안의 x로 보인다. 👀
- [ ] 누르면 바로 아래에 [새 노트로 만들기] / [삭제] 드롭다운. 🤖
- [ ] 커서를 깨진 링크 뒤에 두고 `Ctrl+Enter` → 새 노트로. `Backspace` → 알림 없이 바로 지워짐. 👀

## 5. 복사, 잘라내기, 붙여넣기

- [ ] 링크가 든 줄을 `Ctrl+C` → 다른 곳에 `Ctrl+V` → 링크가 깨진 링크로 붙는다. 🤖
- [ ] 같은 것을 `Ctrl+Shift+V` → 하위 노트까지 새 노트로 복제된다. 복제본을 열어 보면 제목과 본문이 같다. 🤖
- [ ] 줄을 선택하고 `Ctrl+X` → 지워지지 않고 청록 박스가 둘린다. 🤖
  - [ ] 다른 노트에서 `Ctrl+V` → 원래 자리에서 빠지고 여기로 옮겨진다. 옮긴 노트 패널이 새 부모 옆 컬럼으로 간다. 삭제 알림은 뜨지 않는다. 🤖
  - [ ] `Esc`, 다른 것 복사, 박스 안 편집 중 하나를 하면 박스가 풀린다. 🤖(Esc) 👀(나머지)
  - [ ] 노트를 자기 하위 노트 안으로 옮기려 하면 "자기 하위 노트 안으로는 옮길 수 없음" 알림. 🤖
- [ ] 앱에서 복사한 글을 메모장에 붙이면 글만 들어간다(링크 기호는 빠짐). 👀
- [ ] 메모장에서 복사한 글을 앱에 `Ctrl+Shift+V`로 붙이면 그냥 글로 들어간다. 👀

## 6. 패널

- [ ] `Esc` → 선택한 패널이 닫히고 부모 패널로 초점이 간다. 최상위 노트에서는 닫히지 않고 빨간 경고. 🤖
- [ ] `Alt+방향키`로 패널을 옮기면 그 패널에서 바로 글을 쓸 수 있다(마지막 커서 자리). 🤖
- [ ] `Ctrl+Tab` 패널이동모드: 방향키 이동, `Enter` 선택, `Esc` 취소. 🤖
- [ ] 최소화(—) → 제목줄만 남고 하위 패널도 숨음. 복원 → 원래대로. 🤖
- [ ] 우클릭 메뉴: 하위 전체 펼치기 / 접기. 🤖
- [ ] 상단바를 잡고 위아래로 끌어 형제 순서 바꾸기. 부모 본문의 줄 순서도 같이 바뀐다. `Alt+Shift+↑/↓`도 된다. 🤖
- [ ] 제목 글자를 잡고 끌어도 순서가 바뀐다. 그냥 누르면 제목 고치기가 된다. 👀
- [ ] 패널 오른쪽 가장자리 → 컬럼 너비, 아래 가장자리 → 높이, 오른쪽 아래 모서리 → 둘 다. 🤖
- [ ] 여닫기 애니메이션이 부드럽고, 애니메이션 중에 눌러도 씹히지 않는다. 👀

## 7. 화면 (캔버스)

- [ ] 빈 곳을 끌면 화면이 움직인다. 휙 던지면 살짝 미끄러진다. 🤖
- [ ] 끝을 넘어서 끌면 저항이 걸리고 놓으면 튕겨 돌아온다. 🤖
- [ ] 휠로 확대·축소(커서 기준). 긴 본문 위에서는 휠이 본문을 스크롤한다. 🤖
- [ ] `Ctrl+0` → 원래 위치, 100%. 🤖
- [ ] 확대한 상태에서도 글쓰기, 링크, 끌기가 정상이다. 👀

## 8. 저장과 복원

- [ ] 글을 쓰고 1초쯤 뒤 `문서\Nodt\notes\`의 파일이 바뀐다. 🤖
- [ ] md 파일을 VS Code 같은 곳에서 열어 보면 스펙 7.2 형식이다(frontmatter + 본문, 링크는 `[>](nodt:…)`). 🤖
- [ ] 앱을 닫았다 켜면 그대로다. 열린 패널, 선택한 패널, 최소화, 컬럼 너비, 패널 높이, 화면 위치와 확대율이 모두 돌아온다. 🤖(일부)
- [ ] 창을 옮기고 크기를 바꾸고 닫았다 켜면 그 자리, 그 크기로 뜬다. 최대화해서 닫으면 최대화로 뜬다. 🤖
- [ ] `Alt+F4`로 닫아도 저장된다. 👀
- [ ] 작업표시줄에서 창을 닫아도(우클릭 → 창 닫기) 저장된다. 👀
- [ ] 앱이 켜져 있는 동안 `문서\Nodt\backups\5min\`에 스냅샷 폴더가 생긴다. 켠 지 5초 뒤 하나, 그 뒤로 바뀐 게 있으면 5분마다. 🤖

## 9. 창과 설정

- [ ] 프로그램 상단바: 왼쪽 로고와 Nodt, 오른쪽 설정·도움말·최소화·최대화·닫기. 빈 곳을 끌면 창이 움직이고 두 번 누르면 최대화. 👀
- [ ] 창을 가장 작게 줄이면 기본 패널 하나와 사방 여백(연결선 켬 34px, 끔 12px)만큼에서 멈춘다. 👀
- [ ] Windows 11 창 스냅(창을 화면 가장자리로 끌기, `Win+방향키`)이 된다. 👀
- [ ] 설정: 연결선은 켜기가 앞, 테마는 3×2 격자로 간격이 고르다. 창 모드 항목은 없다. 👀
- [ ] 테마 6개, 밝기(라이트/다크/시스템), 연결선, 패널 열기 방식을 바꾸면 바로 적용되고 다시 켜도 남는다. 🤖
- [ ] 하위 노트를 새로 열면 제목과 본문에 안내 글이 없다. 최상위 노트에는 "제목 없음", "내용 · / 로 명령"이 보인다. 🤖
- [ ] 설정 → 데이터 폴더 👀
  - [ ] 경로 칸에 직접 적을 수 있다. 바꾸면 [폴더 고르기] 버튼이 [바꾸기]로 바뀌고, `Enter`나 [바꾸기]로 적용된다.
  - [ ] [폴더 고르기]를 누르면 폴더 고르는 창이 앞에 뜬다. 실패하면 이유가 알림으로 뜬다.
  - [ ] 빈 폴더를 고르면 지금 노트가 그 폴더로 옮겨 써지고 앱이 새로 뜬다.
  - [ ] 노트가 있는 폴더를 고르면 불러올지 묻고, [불러오기]면 그 폴더 노트로 새로 뜬다.
- [ ] 설정 → [백업에서 되돌리기] → 목록에서 고르고 [되돌리기] → 그때 노트로 돌아가고 앱이 새로 뜬다. 🤖
  - [ ] 되돌린 뒤 목록 맨 위에 "되돌리기 직전"이 있고, 그걸로 다시 되돌릴 수 있다. 👀
- [ ] 도움말(?)의 단축키 표가 실제 동작과 맞다. 👀
