## 1. 제품 개요

**한 줄 정의:** 생각 하나에서 다음 생각으로 계속 들어가는 미니멀 노트 앱.

**슬로건 후보:** *Follow your thoughts.* / *Go deeper.*

- 노트를 "어디에 저장할까"가 아니라 "이 생각에서 어디로 더 들어갈까"를 따라가게 한다.
- 폴더, 태그, 데이터베이스, 검색 같은 정리 기능은 의도적으로 뺀다. Note → Note 관계 자체가 제품의 정체성이다.
- 노트를 정리하는 앱이 아니라, 생각을 따라가는 앱으로 포지셔닝한다.

**이름:** Nodt. Node, Note, To를 합쳤고 Nod(끄덕임)도 겹친다. 이전 이름은 Nodto였다.

**타깃 사용자**
- 생각을 자주 메모하는 사람
- 공부하면서 개념을 계속 파고드는 사람
- 개발자
- 아이디어를 많이 기록하는 사람
- 프로젝트를 여러 단계로 쪼개는 사람
- Notion 같은 복잡한 도구가 부담스러운 사람

**다른 앱과의 차이**

| | Notion | Obsidian | Tana | Nodt |
|---|---|---|---|---|
| 폴더 / 태그 / DB | 많음 | 많음 | 많음 | 없음 |
| Note → Note | ✓ | ✓ | ✓ | 핵심 |
| 가로 패널 탐색 | △ | △ | ✓ | 핵심 UX |
| 복잡도 | 높음 | 높음 | 높음 | 최소 |

## 2. 노트 모델

- **트리 구조:** 모든 노트는 부모가 정확히 하나다. 같은 노트를 두 곳에서 링크할 수 없다.
- **최상위 노트:** 부모가 없는 노트다. 여러 개 둘 수 있고, 하나도 없을 수도 있다(빈 화면). 첫 컬럼에 위에서부터 쌓인다.
  - 만들기: 아무 패널도 선택하지 않은 상태(빈 곳 클릭)에서 `Ctrl+N`. 첫 컬럼 맨 아래에 생기고 제목에 커서가 간다.
  - 다른 노트처럼 우클릭 메뉴나 `/` 메뉴로 삭제할 수 있다(되돌리기 알림). 닫을 수는 없다.
  - 최상위 노트끼리 순서를 바꿀 수 있다(4.4의 패널 순서 바꾸기와 같다).
- **링크:** 본문 안에 들어가는 **라벨 없는 기호 하나**다.
  - 링크 하나가 자식 노트 하나를 가리킨다.
  - 본문 어디에든 둘 수 있다.
- **자식 순서:** 부모 본문 안에서 링크가 나오는 순서다. 패널을 끌어 순서를 바꾸면 부모 본문의 링크 줄이 옮겨진다(4.4).
- **제목:** 각 패널 상단바의 제목 필드에만 있다. 링크에는 텍스트가 없다.
- **고아 노트 없음:** 링크되지 않은 노트는 존재하지 않는다.
  - 링크를 지우면 그 아래 노트들도 사라진다.
  - 노트 목록, 검색, 백링크 화면은 없다.
- **ID:** UUID.

## 3. 링크

### 3.1 만들기
1. `/` 명령 메뉴에서 "새 노트 링크"를 고르거나 `Ctrl+N`을 누른다.
   - 본문에서 누르면 커서 자리에 링크가 생긴다.
   - 제목에 커서가 있거나 패널만 선택한 상태면 본문 끝 새 줄에 링크가 생긴다. 본문이 목록으로 끝나면 목록 항목이 하나 늘어난다. 최소화된 패널이면 복원된다.
   - 아무 패널도 선택하지 않았으면 새 최상위 노트를 만든다(2장).
2. 빈 자식 노트가 즉시 생기고 다음 컬럼에 열린다.
   - 제목이 비어 있는 동안 제목 칸에는 부모 본문에서 링크 앞에 쓴 글이 흐리게 보인다("장보기 [>]" → "장보기"). 같은 줄의 앞 링크 뒤부터 이 링크 앞까지다. 없으면 비워 둔다. 안내일 뿐 제목이 되지는 않는다. 최상위 노트는 "제목 없음"(영어 Untitled).
3. 커서가 새 노트의 **제목 필드**로 이동한다.
4. 제목에서 `Tab`이나 `Enter`를 누르면 본문으로 넘어간다.
5. 본문 첫 줄에서 `↑`를 누르면 제목으로 돌아간다. (`Shift+Tab`은 리스트 내어쓰기와 겹쳐서 쓰지 않는다.)

### 3.2 열기 / 닫기
- 링크를 **클릭**하면 열리거나 닫힌다.
- 키보드로는 커서를 링크 **바로 뒤**에 두고 `Ctrl+Enter`를 누른다.
- 커서가 링크 뒤에 올 때 드롭다운 메뉴는 띄우지 않는다. 드롭다운의 Enter가 줄바꿈과 충돌하기 때문이다.

### 3.3 표시
| 상태 | 아이콘 | 모양 |
|---|---|---|
| 열림 | < (누르면 닫힘) | 강조색 테두리 원 |
| 닫힘 | > (누르면 오른쪽으로 열림) | 강조색으로 채운 원 |
| 깨진 링크 | x | 빨간 테두리 원 |

### 3.4 삭제
**본문에서 링크 기호를 지울 때** (2026-09-27 변경: 확인 창 → 되돌리기 알림)
- Backspace, Delete, 선택 영역 삭제로 링크 기호가 지워지면 자식 노트와 서브트리가 바로 삭제되고, 우클릭 삭제와 같은 **되돌리기 알림**이 뜬다.
- [되돌리기]나 `Ctrl+Z`(전역 되돌리기, 5.1)를 누르면 서브트리까지 전부 돌아온다. 링크를 다른 텍스트와 함께 지운 경우도 같다.
- 알림이 사라지면 삭제가 확정된다. 그 뒤에는 백업 스냅샷(7.4)만 남는다.

**패널 상단바 우클릭 메뉴의 [노트 삭제]를 고를 때**
- 확인 창 없이 그 노트와 서브트리가 바로 삭제된다. 부모 본문에서는 링크 기호만 빠지고 주변 글은 남는다.
- 대신 화면 아래에 **되돌리기 알림**이 약 8초 뜬다. 예: "'Parser 구현' 삭제됨 · 하위 노트 2개 포함 [되돌리기 Ctrl+Z]"
- [되돌리기]나 `Ctrl+Z`를 누르면 노트, 서브트리, 링크 위치, 열림 상태까지 그대로 돌아온다. 알림이 사라진 뒤에도 `Ctrl+Z`로 되돌릴 수 있다(앱을 끄기 전까지). 삭제 뒤에 다른 동작을 하면 알림의 [되돌리기] 버튼은 사라진다(되돌리기는 나중에 한 것부터라서).
- 알림이 사라지거나 다른 알림으로 바뀌면 삭제가 확정된다.
- 최상위 노트도 같은 방식으로 삭제한다. 되돌리면 원래 순서 자리로 돌아온다.
- 키보드로 삭제하는 방법은 v0.1-b의 `/` 메뉴에 넣는다.

### 3.5 복사 / 잘라내기 / 붙여넣기
| 동작 | 결과 |
|---|---|
| `Ctrl+C` → `Ctrl+V` | 링크가 **깨진 링크**로 붙는다. 부모가 하나뿐이라 같은 노트를 두 곳에 둘 수 없다. |
| `Ctrl+C` → `Ctrl+Shift+V` | 하위 노트까지 **전부 복제**해서 붙인다. 복제된 노트는 모두 새 UUID를 받는다. |
| `Ctrl+X` → `Ctrl+V` | **이동**이다. UUID가 유지되고 부모만 바뀐다. 다른 노트로 옮겨도 된다. |

**잘라내기 규칙**
- `Ctrl+X`를 누르면 선택 영역은 바로 사라지지 않고, 둘레에 **실선 박스**가 표시된다. 엑셀의 잘라내기 방식과 같다.
- 붙여넣는 순간 원래 자리에서 사라지고 새 위치로 옮겨진다.
- 다음 경우에는 잘라내기가 취소되고 박스도 사라진다.
  - `Esc`를 누를 때
  - 다른 것을 복사할 때
  - 박스 안을 편집할 때
  - 앱을 닫을 때
- 자기 자신의 하위 노트 안으로는 옮길 수 없다(순환 방지). 시도하면 "자기 하위 노트 안으로는 옮길 수 없음" 알림이 뜨고 잘라내기가 풀린다.
- 옮긴 노트의 열림 상태는 그대로다. 패널은 새 부모 옆 컬럼으로 옮겨진다.

**클립보드**
- 앱 밖으로 복사하면 글만 간다. 링크 기호는 빠진다.
- `Ctrl+Shift+V`의 하위 노트 복제는 앱 안에서 복사한 것일 때만 된다. 클립보드 글이 앱 안에서 마지막으로 복사한 글과 같은지로 판단한다. 다른 곳에서 복사한 글은 서식 없이 붙는다.

### 3.6 깨진 링크
- **생기는 경우:** `Ctrl+V`로 붙인 링크, 삭제 후 `Ctrl+Z`로 되돌린 링크.
- **새 노트로 만들기:** 커서를 깨진 링크 바로 뒤에 두고 `Ctrl+Enter`를 누른다. 빈 자식 노트가 생기고 링크가 연결된다.
- **삭제:** `Backspace`. 확인 창 없이 바로 지워진다.
- **마우스 클릭:** 칩 바로 아래에 드롭다운이 뜬다: [새 노트로 만들기] / [삭제]. 방향키와 `Enter`로 고르고 `Esc`로 닫는다.

## 4. 화면 구조: 컬럼과 패널

### 4.1 컬럼 = 깊이
```text
컬럼 1       컬럼 2          컬럼 3              컬럼 4
[오늘]       [CS 142A]       [Compiler Project]  [Parser 구현]
             [앱 개발]       [중간고사 범위]
```
- 컬럼 1은 최상위 노트들, 컬럼 2는 그 자식들, 컬럼 3은 손자들이다.
- **한 노트의 자식 여러 개를 동시에 열 수 있다**(기본 "추가" 모드).
- 같은 깊이의 열린 노트들은 같은 컬럼 안에 세로로 쌓인다.
  - 순서는 트리 순서를 따른다. 부모끼리의 순서가 먼저이고, 같은 부모 안에서는 링크 순서다.
- 설정에서 **"교체" 모드**(Miller columns)를 고를 수 있다. 자식을 열면 같은 부모의 다른 열린 자식은 닫힌다.
- 컬럼 수는 열린 트리의 깊이만큼 늘어난다.
- **캔버스:** 스크롤바가 없다. 컬럼은 내용만큼 아래로 늘어나고, 화면 밖은 캔버스처럼 옮겨서 본다.
  - 패널 밖 빈 곳을 끌면 전체가 움직이고, 놓은 자리에 머문다.
  - 스크롤 끝처럼 경계가 있다. 가장자리 패널과 화면 끝 사이가 간격을 넘으면 저항이 걸리고(넘은 거리의 30%만 따라옴), 놓으면 경계로 튕겨 돌아온다.
    - 간격은 가로세로 모두 34px(연결선을 켰을 때의 컬럼 간격)로 고정이다. 연결선을 꺼도 같다. 확대율에 따라 같이 변한다.
    - 내용이 화면보다 크면: 내용 양 끝 사이에서 자유롭게 움직인다.
    - 내용이 화면보다 작으면: 처음 자리(왼쪽 위 여백 12px)에서 움직이자마자 저항이 걸린다.
  - 관성: 휙 끌고 놓으면 살짝 미끄러지다 멈춘다. 경계를 넘으면 빨리 멈추고 경계로 돌아온다.
  - 휠로 확대·축소한다(30~200%, 커서 위치 기준). 본문이 길어서 스크롤되는 패널 위에서는 휠이 본문을 스크롤한다.
  - `Ctrl+0`: 원래 위치, 100%로 돌아간다.
  - 키보드로 선택을 옮겨서 선택한 패널이 화면 밖으로 나가면 화면이 부드럽게 따라간다. 따라간 자리도 끌기 경계 안으로 맞춘다(경계 밖에 두면 다음 끌기에서 처음부터 저항이 걸려 경계가 달라진 것처럼 느껴진다). 패널이 닫혀 내용이 줄었거나 창 크기가 바뀌어 경계 밖이 되면 안으로 옮긴다.
- 하위 노트는 오른쪽으로 열린다. 방향 설정은 두지 않는다.

### 4.2 크기
- **창 크기와 무관:** 프로그램 창 크기를 바꿔도 컬럼 너비와 패널 높이는 변하지 않는다. 창이 작아지면 캔버스를 옮겨서 본다.
- **컬럼 너비**
  - 기본값은 256px이다(기본 창 1280px의 약 1/5). 아무 패널의 오른쪽 가장자리를 좌우로 끌어 조절한다. 같은 컬럼의 패널은 너비를 공유해서 전부 같이 바뀐다.
  - 같은 컬럼의 패널들은 너비를 공유한다. 이 방식은 실제 화면을 보고 다시 검토한다.
- **패널 높이**
  - 기본값은 200px이다(기본 창 720px에 세 개가 들어가는 높이). 아래 가장자리를 위아래로 끌어 조절할 수 있다.
- **모서리:** 패널 오른쪽 아래 모서리를 끌면 높이와 컬럼 너비가 한 번에 바뀐다.
  - 본문이 패널보다 길면 패널 안에서 스크롤된다.

### 4.3 패널 상단바
창의 제목 표시줄처럼 버튼을 최소화와 `x` 두 개만 둔다. 상단바 아래에 1px 구분선을 그어서 끌 수 있는 영역(상단바)이 보이게 한다.
```text
일반 노트:   [제목 필드 ...............] [— 최소화] [x 닫기]
최상위 노트: [제목 필드 ...............] [— 최소화]
```
- 설정과 단축키 도움말은 프로그램 상단바(8.1)에 있다.
- **제목:** 평소에는 상단바의 일부다. 한 번 누르면 패널 선택, 끌면 순서 바꾸기다. **두 번 눌러야** 제목을 고칠 수 있고 커서는 제목 끝에 간다. 새 노트를 만들 때나 본문 첫 줄에서 `↑`를 누를 때처럼 키보드로 들어오면 바로 고칠 수 있다.
- 상단바를 우클릭하면 메뉴가 뜬다: [하위 전체 펼치기] [하위 전체 접기] | [노트 삭제]. 방향키와 `Enter`로도 고를 수 있다.

### 4.4 열기 / 닫기 규칙
- **열기:** 링크를 누를 때마다 열림과 닫힘이 바뀐다(토글).
- **닫기:** 선택한 패널에서 `Ctrl+W`를 누르거나, 상단바의 `x`를 누르거나, 부모 패널의 열린 링크(<)를 누른다. `Esc`는 닫지 않고 선택만 푼다(4.5).
  - 닫은 패널은 `Ctrl+Z`(전역 되돌리기)로 다시 열린다(하위 패널도 전처럼).
  - **빈 새 노트는 없었던 일로:** 제목도 본문도 비어 있는 노트(막 만들고 아무것도 안 쓴 노트)에서 `Esc`나 `Ctrl+W`를 누르면 노트와 부모 본문의 링크가 함께 사라진다. 알림은 없다(`Ctrl+Z`로 되돌릴 수는 있다). `Ctrl+W`면 하위 노트는 부모 본문의 원래 커서 자리로 돌아가고, `Esc`면 선택이 풀린다.
  - 그 패널의 **하위 노트도 전부 함께 닫힌다**(화면에서 사라짐).
  - 대신 하위 노트들의 **열림 상태는 기억**한다. 다시 열면 하위 노트도 전에 열려 있던 그대로 열린다.
- **최소화:** 패널이 제목줄만 남기고 접히고, 하위 노트 패널도 화면에서 사라진다. 다시 누르면(복원) 패널과 하위 노트가 전에 열려 있던 그대로 돌아온다.
- **삭제:** 상단바 우클릭 메뉴. 3.4 참고.
- **패널 순서 바꾸기:** 패널 상단바를 끌면 같은 부모의 형제 패널 사이에서 순서가 바뀐다. `Alt+Shift+↑/↓`로도 된다. 최상위 노트는 최상위 노트끼리 바뀐다.
  - 패널은 어디로든 끌리지만, 순서를 바꿀 수 있는 곳(자기 컬럼, 형제 패널 구간) 밖으로 나간 거리는 30%만 따라오는 저항이 걸린다.
  - 상단바를 잡고 끄므로 패널 윗변이 움직인 거리로 자리를 정한다. 옆 형제 자리(높이 + 간격)의 절반을 넘게 끌면 그 자리로 간다. 위아래 같고 패널 높이가 달라도 같다.
  - 순서는 형제끼리만 바뀐다. 부모가 다른 패널(사촌) 사이로 옮기는 건 부모를 바꾸는 이동이라 `Ctrl+X` → `Ctrl+V`로 한다.
  - 끄는 동안 다른 형제 패널이 비켜주고, 놓으면 새 자리로 부드럽게 들어간다.
  - 실제로는 부모 본문의 링크 순서가 바뀐다. 링크가 줄에 혼자 있으면 그 줄을 통째로 옮기고, 한 줄에 링크가 여럿이면 링크 기호만 옮긴다.
- **애니메이션:** 패널이 열리고 닫히고 최소화될 때 약 0.3초 동안 부드럽게 움직인다. 연결선도 매 프레임 따라간다. 새 패널은 왼쪽에서 살짝 미끄러지며 나타나고, 닫힌 패널은 왼쪽으로 사라지고, 나머지 패널은 새 자리로 옮겨간다. 애니메이션 중에도 바로 누르거나 입력할 수 있다. 시스템의 "애니메이션 줄이기"가 켜져 있으면 끈다.
- **하위 전체 펼치기 / 접기:** 상단바 우클릭 메뉴에 있다. 최소화된 패널에서 펼치면 복원도 함께 된다.
  - 펼치기는 모든 하위 노트를 끝까지 재귀적으로 연다. 열릴 노트가 약 30개를 넘으면 "하위 노트 N개를 모두 열까요?" 확인 창을 띄운다.
  - 접기는 모든 하위 노트를 닫고, 열림 상태 기억도 **초기화**한다.
- **최상위 노트**
  - 앱 종료는 프로그램 상단바의 닫기 버튼으로 한다.
  - `Esc`: 다른 패널과 같이 선택만 푼다. (예전의 빨간 경고는 없앴다.)
  - `Ctrl+W`: 최소화한다. 최소화된 상태에서 다시 누르면 복원한다.
- **여는 애니메이션:** 앱을 열 때(초기화로 화면을 새로 만들 때도) 패널이 왼쪽 컬럼부터 위에서 아래로 하나씩 나타난다. 간격 70ms(패널이 많으면 전체 0.7초 안), 하나당 0.3초. 연결선은 마지막 패널이 자리 잡을 즈음 나타난다. 시스템의 "애니메이션 줄이기"가 켜져 있으면 끈다.
- **앱 시작:** 마지막 상태를 복원한다. 열린 노트, 기억된 열림 상태, 최소화, 선택한 패널, 컬럼 너비, 패널 높이, 캔버스 위치와 확대율, 창 위치와 크기, 최대화가 포함된다.
- **처음 켤 때:** 데이터 폴더에 노트가 없으면 사용법 노트를 만든다. 완전 초기화한 뒤나 노트를 모두 지운 뒤에는 빈 화면 그대로 켜진다(가운데에 "`Ctrl+N` 으로 새 노트" 안내).
  - 영어(기본)와 한국어 두 벌이 있고, 만들 때의 언어 설정으로 만든다. 언어를 바꿔도 이미 만든 사용법 노트는 그대로다. 아래 제목은 한국어 판이다(영어 판: How to use Nodt, Example 1: This week's to-dos, Example 2: Reading log).
  - 최상위 노트는 셋이다: "Nodt 사용법", "예제 1: 이번 주 할 일", "예제 2: 독서 기록". 예제는 누구나 쓸 법한 일상 내용으로 한다.
  - "Nodt 사용법" 아래에 파트별 하위 노트 7개(시작하기, 링크와 새 노트, 패널 다루기, 화면 옮기기, 복사와 이동, 저장과 설정, 서식)가 있다. "시작하기" 아래에는 "연습장"이 있다.
  - 처음에는 "시작하기"(와 연습장)만 펼쳐져 있고, "링크와 새 노트"는 열려 있되 최소화돼 있다. 나머지 파트는 닫혀 있다. 선택한 패널은 "시작하기"다.
  - 예제 두 개는 최소화돼 있다. 복원하면 하위 노트가 두세 단계 펼쳐진 실제 사용 모습이 보인다(열림 상태를 기억시켜 둠).
  - 내용은 앱 코드(`src/model/tutorial.ts`)에 있고, 만들 때마다 일반 노트로 저장된다. 따로 보관하는 원본 파일은 없다.
  - **잘리지 않게:** 사용법 노트 패널은 처음 화면에 보일 때 내용 높이를 재서 그 높이로 연다(기본 높이보다 작게는 안 줄임, 최대 480px). 최소화된 예제는 복원할 때 잰다.
  - **전체가 한 화면에:** 사용법 노트가 창보다 크면 창을 키우고(모니터 작업 영역까지, 가운데로) 처음 자리에서 보여준다. 그래도 넘치면 캔버스를 축소한다. 최대화 상태면 창은 그대로 둔다.
- **초기화:** 프로그램 상단바의 설정 왼쪽 버튼. 누르면 반드시 확인 창을 띄운다(기본 초점은 [취소], `Esc`로 닫힘).
  - 확인 창에서 두 가지 중 고른다.
    - **완전 초기화** (위, 기본 선택): 모든 노트와 화면 배치를 지우고 빈 화면에서 시작한다.
    - **사용법 노트로:** 모든 노트와 화면 배치를 지우고 처음 켤 때의 사용법 노트로 돌아간다.
    - 설정은 앱 전체에 걸친 것이라 어느 쪽이든 그대로 둔다.
  - 어느 쪽이든 지우기 전에 지금 노트를 저장하고 데이터 폴더의 `backups\reset\<UTC 시각>`에 한 벌 복사한다. `backups\reset`은 순환하지 않는다.

### 4.5 선택한 패널
- 강조색 테두리와 옅은 링으로 표시한다.
- 클릭하거나 키보드(5장)로 선택을 옮긴다.
- 패널 밖 빈 곳을 끌지 않고 누르면 선택이 풀리고 글 입력 초점도 빠진다. 이 상태에서 `Ctrl+N`은 새 최상위 노트를 만들고, `Alt+방향키`나 `Ctrl+Tab`은 맨 위 최상위 노트부터 시작한다. 선택이 없는 상태도 저장된다.
- 순서 바꾸기나 새 노트로 선택한 패널이 화면 밖으로 밀려나면 애니메이션이 끝난 뒤 화면이 따라간다.

### 4.6 관계 표시
**맨 위 선 그라데이션** (기본, 항상 켜짐)
- 패널 맨 위에 굵은 선(8px)을 긋는다. 상단바 배경에는 색을 칠하지 않는다.
- 선택한 패널의 선이 가장 진하다. 100%는 강조색 그대로라 닫힌 링크 칩(채운 알약)과 같은 색이다.
- **계보**를 따라 한 칸 갈 때마다 **30%p씩** 옅어진다: 100% → 70% → 40% → 10% → 0%.
  - 계보는 선택한 노트에서 **위로만**(부모, 조부모…) 또는 **아래로만**(자식, 손자…) 이어지는 노트다.
- 계보 밖의 패널은 **무조건 0%**다. 같은 컬럼의 다른 패널, 형제, 사촌이 여기에 해당한다. 관련이 없기 때문이다.
- 진하기 N%는 강조색을 패널 배경에 N% 섞은 색이다.
- 선의 최저 밝기는 10%다. 계보 밖 패널의 선도 10%로 칠해서 흰 띠로 보이지 않게 한다(테두리는 계보 밖이면 0%).
- 패널 테두리도 같은 비율을 따른다. 100%일 때 강조색을 55% 섞는다.

예: **Compiler Project**를 선택했을 때 (4.1 그림 기준)

| 패널 | 관계 | 진하기 |
|---|---|---|
| Compiler Project | 선택 | 100% |
| CS 142A | 부모 | 70% |
| Parser 구현 | 자식 | 70% |
| 오늘 | 조부모 | 40% |
| 중간고사 범위 | 형제 (같은 컬럼) | 0% |
| 앱 개발 | 계보 밖 | 0% |

**연결선** (설정 옵션, 기본 켜짐)
- 부모 패널 오른쪽 가장자리에서 시작해 자식 패널 제목 높이까지 곡선을 긋는다. 시작 높이는 해당 링크가 있는 줄이다.
- 선택한 노트의 계보에 있는 선은 강조색으로 그린다.
- 선을 켜면 선이 지나갈 자리를 위해 컬럼 사이 간격이 12px에서 34px로 넓어진다.

## 5. 키보드 조작

마우스를 거의 쓰지 않아도 되게 하는 것이 설계 원칙이다.

| 키 | 동작 |
|---|---|
| `Ctrl+Enter` | 커서 바로 앞의 링크 열기/닫기. 깨진 링크면 새 노트로 만들기 |
| `Ctrl+N` | 새 노트 링크 만들기(3.1). 선택한 패널이 없으면 새 최상위 노트 |
| `Ctrl+W` | 선택한 패널 닫기. 최상위 노트면 최소화 / 복원 |
| `/` | 명령 메뉴. 줄 맨 앞이나 공백 뒤에서만 뜬다. `Esc`를 누르거나 맞는 항목이 없으면 그냥 `/` 문자가 된다. 항목: 새 노트 링크, 부제목, 글머리 목록, 체크 목록, 이 노트 삭제. 글자를 더 치면 걸러진다. |
| `Tab` / `Enter` / `↓` (제목에서) | 본문으로 이동 |
| `↑` (본문 첫 줄에서) | 제목으로 이동 |
| `Tab` / `Shift+Tab` (리스트에서) | 들여쓰기 / 내어쓰기 |
| `Esc` | 선택 풀기(빈 곳을 누른 것과 같다. 글 입력 초점도 빠진다). 패널은 닫지 않는다. 메뉴, 오버레이, 모드, 오류 알림, 잘라내기 박스가 떠 있으면 그것부터 닫는다. |
| `Alt+←` | 부모 패널로 이동 |
| `Alt+→` | 첫 번째로 열린 자식 패널로 이동 |
| `Alt+↑` / `Alt+↓` | 같은 컬럼의 위 / 아래 패널로 이동 |
| `Alt+Shift+↑` / `Alt+Shift+↓` | 선택한 패널을 같은 부모 안에서 위 / 아래로 옮기기 |
| `Ctrl+0` | 화면을 원래 위치, 100%로 |
| `Ctrl+Tab` | 패널이동모드 |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` / `Ctrl+Shift+V` | 3.5 참고 |
| `Ctrl+Z` | 전역 되돌리기(5.1) |
| `Ctrl+Shift+Z` / `Ctrl+Y` | 다시 실행 |
| `Ctrl+B` / `Ctrl+Shift+S` | 굵게 / 취소선 |
| `Backspace` (깨진 링크 뒤에서) | 깨진 링크를 바로 삭제 |

- `Ctrl+방향키`는 쓰지 않는다. 사용자가 텍스트 편집 중 단어 단위 이동으로 자주 쓰는 키다.
- `Tab`은 리스트 들여쓰기에 쓰므로 패널 이동에 쓰지 않는다.

**패널이동모드** (v0.1에 포함)
- `Ctrl+Tab`으로 들어간다.
- 들어가면 패널 전체가 살짝 축소되고, 선택한 패널에 테두리가 강조된다.
- 방향키로 이동한다.
- `Enter`를 누르면 그 패널에서 편집을 시작한다.
- `Esc`를 누르면 취소하고 원래 패널로 돌아간다.

### 5.1 전역 되돌리기
- 앱 전체에 되돌리기 기록이 하나 있다. 커서가 어느 노트에 있든 `Ctrl+Z`는 가장 최근 동작부터 되돌리고, `Ctrl+Shift+Z`(`Ctrl+Y`)는 다시 실행한다. 에디터와 제목 칸의 자체 되돌리기는 쓰지 않는다.
- **기록하는 것:** 글과 제목 고치기, 노트 만들기·지우기, 패널 열기·닫기·최소화, 하위 전체 펼치기·접기, 순서 바꾸기, 잘라내서 옮기기, 붙여넣기, 깨진 링크 고치기.
- **기록하지 않는 것:** 선택 이동, 설정, 화면 이동·확대, 패널 크기 조절, 초기화(초기화는 백업으로 살린다).
- **묶음:** 한 번의 동작 안에서 같이 일어난 변화는 한 단계다(예: `Ctrl+N`의 새 노트와 링크, 잘라낸 것 빼기와 붙이기). 이어서 친 글은 같은 노트, 같은 칸(제목/본문)이면 1초 안의 멈춤까지 한 단계로 묶는다(최대 5초). 링크가 생기거나 없어진 편집은 따로 한 단계다.
- 되돌리면 그때 선택했던 패널이 다시 선택되고, 에디터 커서는 바뀐 자리 끝으로 간다. 화면도 그 패널을 따라간다.
- 새 동작을 하면 다시 실행할 기록은 버린다. 기록은 최근 300단계까지이고 저장하지 않는다(앱을 끄면 사라진다).

## 6. 에디터

- **라이브러리:** Tiptap. 링크 기호는 커스텀 인라인 노드로 만든다.
- **지원 서식:** 굵게, 취소선, bullet 리스트, 체크박스, 부제목(한 단계). 제목은 상단바에 있다.
- **지원하지 않음:** 기울임, 여러 단계의 헤딩, 표, 이미지, 임베드. 붙여넣은 글에 있으면 빠진다.
- **입력 규칙:** `## ` 부제목, `- ` 글머리 목록, `[ ] ` 체크 목록, `**굵게**`, `~~취소선~~`.
- **빈 본문:** 최상위 노트의 본문이 통째로 비어 있을 때만 "/로 명령"(영어 "/ for commands") 자리표시 글을 옅게 보여준다. 새 줄마다 보이지는 않는다.

## 7. 저장

### 7.1 폴더 구조
```text
문서\Nodt\                     ← 데이터 폴더 (설정에서 변경 가능)
├── notes\
│   ├── <uuid>.md               ← 노트 하나 = 파일 하나 (평평한 구조)
│   └── ...
├── state.json                  ← 최상위 노트 순서, 열림 상태, 기억된 하위 열림 상태, 최소화, 선택 패널,
│                                  컬럼 너비, 패널 높이, 캔버스 위치·확대율, 창 위치·크기
└── backups\
    ├── 5min\  2h\  1d\  1w\  1m\
        └── <YYYYMMDD-HHMMSSZ>\   ← notes\ 와 state.json 복사본
```
- 데이터 폴더 위치와 설정은 데이터 폴더가 아니라 앱 설정 폴더(`%APPDATA%\app.nodt.desktop\config.json`)에 둔다. 데이터 폴더를 옮겨도 설정이 따라간다.
- 최상위 노트들에서 닿는 노트만 저장한다.
  - frontmatter의 `parent`가 빈 파일은 최상위 노트로 보여준다(`state.json`의 순서에 없으면 만든 순서로 뒤에 붙인다). 밖에서 폴더에 넣은 md 파일도 이렇게 나타난다.
  - `parent`가 있는데 그 부모 본문에 링크가 없는 파일은 불러오되 화면에 보이지 않고, 지우지도 않는다.
- 폴더 트리 대신 **평평한 구조**를 쓴다.
  - 부모를 바꿀 때 링크 한 줄만 고치면 된다.
  - 제목을 바꿔도 파일 이름이 바뀌지 않는다.
  - 대신 탐색기에서 보면 파일 이름이 UUID라 알아보기 어렵다.
- 트리 구조의 기준은 **부모 본문 안의 링크**다. frontmatter의 `parent`는 빠른 조회와 무결성 확인용이다.

### 7.2 md 표기 (GFM)
```markdown
---
id: 3f2a9c1e-...
title: "Compiler Project"
parent: 9b1c4d7a-...
created: 2026-09-27T14:05:00+09:00
updated: 2026-09-27T15:12:00+09:00
---
## 단계
- [x] Lexer
- [ ] Parser 구현 [>](nodt:5e8f...)
- **굵게** ~~취소선~~
```
- **링크:** `[>](nodt:<uuid>)`. 표준 마크다운 링크 형식이라 다른 마크다운 뷰어에서 열어도 깨지지 않는다.
- **깨진 링크:** `[>](nodt:broken)`.
- **제목:** 따옴표로 감싼 문자열이다(JSON 문자열이라 YAML에서도 그대로 읽힌다).
- **목록 들여쓰기:** 2칸마다 한 단계.
- **빈 문단:** 블록 사이 빈 줄 하나는 구분이고, 그보다 많은 빈 줄 하나마다 빈 문단 하나다.
- **특수문자:** 글 안의 `*`, `~`, `\`, `[>]`는 역슬래시로 막는다. 문단이 `- `나 `#`으로 시작하면 앞에 역슬래시를 붙인다.
- frontmatter가 없는 md 파일도 읽는다. 제목은 비어 있다.

### 7.3 실시간 저장
- 입력이 멈추고 약 1초 뒤에 저장한다(debounce).
- 앱을 닫을 때도 즉시 저장한다. 창의 닫기 버튼, `Alt+F4` 모두 저장을 마친 뒤 닫힌다.
- 바뀐 노트만 쓴다. 부모가 바뀐 노트(frontmatter의 parent)도 다시 쓴다.
- 삭제한 노트의 파일은 바로 지운다. `Ctrl+Z`로 되살리면 다시 쓴다. 앱을 끈 뒤에는 백업에서 되돌리기로 살린다.
- **원자적 쓰기**를 쓴다. 임시 파일에 먼저 쓰고 원래 파일과 교체하므로, 저장 중에 앱이 꺼져도 파일이 깨지지 않는다.

### 7.4 백업 스냅샷
| 주기 | 보관 개수 | 커버 범위 |
|---|---|---|
| 5분 | 12 | 최근 1시간 |
| 2시간 | 12 | 최근 1일 |
| 1일 | 7 | 최근 1주 |
| 1주 | 4~5 | 최근 1달 |
| 1달 | 12 | 최근 1년 |

- 가장 오래된 것부터 교체하는 순환 방식이다.
- 폴더 이름은 UTC 시각(`20260927-141500Z`)이라 서로 겹치지 않고, 이름 순서가 시간 순서다.
- 앱이 켜져 있는 동안 1분마다(그리고 켠 뒤 5초에) 주기가 된 단계만 스냅샷을 만든다. 앱이 꺼져 있던 동안의 스냅샷은 없다.
- 마지막 스냅샷과 노트 내용이 같으면 건너뛴다.
- **백업에서 되돌리기:** 설정 → 데이터 폴더 아래 [백업에서 되돌리기].
  - 목록은 최신 것부터 "오늘 14:05 · 5분 단위 · 노트 19개"처럼 보인다. 내용이 같은 스냅샷(여러 단계에 동시에 남은 것)은 하나만 보인다. 초기화 직전(`reset`), 되돌리기 직전(`restore`) 백업도 들어 있다.
  - 방향키로 고르고 `Enter` → 확인 창 → [되돌리기]. 노트와 화면 배치가 그때로 돌아가고 앱이 새로 뜬다.
  - 되돌리기 전에 지금 상태를 `backups\restore\<UTC 시각>`에 남긴다(순환하지 않음). 그래서 되돌린 것도 다시 되돌릴 수 있다.
  - 노트는 새 폴더에 먼저 모두 복사한 뒤 `notes` 폴더와 바꿔치기한다. 중간에 실패하면 지금 노트가 그대로 남는다.

## 8. 창

### 8.1 v0.1: 일반 창
- 테두리 없는 창에 얇은 자체 상단바(프로그램 상단바, 32px)를 둔다. Windows 기본 제목 표시줄은 쓰지 않는다.
  ```text
  [Nodt ........................ ↺ 초기화  ⚙ 설정  ? 도움말 | —  □  ✕]
  ```
  - 빈 곳을 끌면 창이 움직이고, 두 번 누르면 최대화된다.
  - 창 버튼은 최소화, 최대화/이전 크기, 닫기(앱 종료)다.
- **가장 작은 창:** 기본 크기 패널(244×200) 하나에 사방 34px(끌기 저항 경계) 여백을 둔 312×300이다(프로그램 상단바 32 포함). 연결선 설정과 상관없다.
- 창 위치와 크기, 최대화를 기억한다. 창을 보이기 전에 되돌리므로 켤 때 튀지 않는다. 저장된 위치가 어느 모니터에도 없으면 가운데에 둔다. Windows 11 창 스냅 기능을 그대로 쓸 수 있다.
- **배경 효과(Mica / Acrylic, 9장 설정):** 창 배경과 프로그램 상단바가 반투명해져 뒤가 비친다. Mica는 바탕화면 색만 은은하게, Acrylic은 뒤에 있는 창까지 뿌옇게 비친다. 아래는 Mica 기준이다. 창 배경과 프로그램 상단바가 반투명해져 바탕화면 색이 은은하게 비친다. 패널은 불투명하다. 앱의 밝기(라이트/다크)에 맞춰 밝은/어두운 Mica를 쓴다. 창이 비활성이면 Windows가 단색으로 바꾼다. Windows 10에서는 지금처럼 불투명한 배경이다. 설정 항목은 없다.
- 작업표시줄에 아이콘이 있다. 시스템 트레이 모드는 옵션 후보다.
- 창 모드 설정은 없다. 늘 일반 창이다(다른 프로그램을 누르면 그 뒤로 가려진다). 항상 위, 전역 단축키로 불러오기는 필요 없다고 정했다.

### 8.2 v0.2: 플로팅 모드 (설정 옵션)
- 투명한 전체화면 창을 쓴다(Bongo Cat 방식). 창 테두리와 배경 없이 **노트 패널만 바탕화면 위에 떠 있는 것처럼** 보인다.
- 투명한 부분을 클릭하면 뒤에 있는 바탕화면이나 프로그램이 눌린다. 마우스가 패널 위에 있을 때만 클릭을 받는다.
- 창은 작업표시줄을 가리지 않는다.
- 패널은 불투명하게 하고 그림자를 진하게 준다. 배경화면이 무엇이든 글이 잘 읽혀야 하기 때문이다.
- **패널 묶음 위치:** 기본은 화면 왼쪽 끝이다. 드래그로 옮길 수 있다.
- **넘칠 때**
  - 선택한 패널이나 새로 연 패널이 화면 밖에 있으면 패널 묶음을 자동으로 밀어서 보이게 한다.
  - 패널 위에서 `Shift+휠`로 옆으로 밀 수 있다.
- 여러 모니터 처리는 미정이다.
- v0.1부터 패널 영역을 창과 분리해서 만든다. 나중에 창 배경만 투명하게 바꾸면 이 모드를 붙일 수 있게 하기 위해서다.
