### v0.1-a에서 정한 구현 방식

- **본문 데이터:** 메모리에서도 본문을 실제 저장 형식인 md 문자열(`[>](nodt:<uuid>)`)로 둔다. 자식 순서는 스펙대로 본문 링크 순서에서 계산한다. 본문 렌더러(`src/ui/NoteBody.tsx`)는 v0.1-b에서 Tiptap으로 바뀌는 임시 코드다.
- **패널 영역 분리:** `Workspace` 컴포넌트가 패널 영역이고 창과 분리돼 있다(스펙 8.2).
- **패널 높이 조절:** 목업은 브라우저 기본 손잡이(패널 오른쪽 아래 모서리)였다. 앱에서는 패널 아래 가장자리를 위아래로 끄는 방식으로 바꿨다. 컬럼 너비 손잡이와 같은 모양이다.
- **목업과 다르게 스펙을 따른 곳:** 패널이동모드에서 `Esc`를 누르면 원래 패널로 돌아간다. 목업은 이동한 패널에 머물렀다.
- **작은 추가:** 패널이동모드에서 `Ctrl+Tab`을 한 번 더 누르면 `Enter`처럼 확정된다.
- **설정 창:** 목업 바깥 버튼이던 연결선, 테마, 밝기를 설정 창 안에 넣었다. 설정 화면 마무리는 v0.1-d다.
- **창:** `decorations: false`로 테두리 없는 창을 쓴다. 프로그램 상단바(`src/ui/TitleBar.tsx`)에 `data-tauri-drag-region`을 달아 끌기와 두 번 눌러 최대화를 처리한다. 필요한 창 권한은 `src-tauri/capabilities/default.json`에 있다.
- **여닫기 애니메이션:** `src/ui/transition.ts`의 FLIP 방식이다. 바뀌기 전 패널 위치를 재고, 상태를 바꾸고, 실제 패널을 Web Animations로 옛 자리에서 새 자리로 옮긴다. 닫힌 패널은 DOM에서 빠진 요소를 `#exit-layer`에 잠깐 올려 사라지게 한다.
  - 처음에는 View Transitions API를 썼다. 하지만 전환 중(0.22초)에는 패널이 클릭을 받지 못해서, 빠르게 연달아 누르면 클릭이 씹혔다. 그래서 FLIP으로 바꿨다.
  - 애니메이션 동안 `nodt:relayout` 신호를 매 프레임 보내고, `Workspace`는 받자마자 연결선을 다시 그린다. rAF로 한 번 더 미루면 계속 취소돼서 선이 끝날 때만 따라왔다.
- **창 끌기:** 프로그램 상단바에서만 끈다. 빈 배경으로 창을 끄는 기능을 잠깐 넣었다가 사용자 요청으로 뺐다.
- **패널 끌어서 순서 바꾸기:** `src/ui/panelDrag.ts`. 끄는 동안은 transform만 바꾸고, 놓으면 `reorder`를 보내 `moveLink`(`src/model/notes.ts`)로 부모 본문의 링크 줄을 옮긴다. 놓인 자리에서 새 자리로는 FLIP 애니메이션으로 들어간다.
  - 사용자는 "같은 컬럼끼리만"이라고 했다. 트리에서 컬럼 안 순서는 부모 순서가 먼저라서, 형제끼리만 바꿀 수 있게 했다. 사촌 사이 이동은 부모 변경이라 `Ctrl+X` 방식에 맡긴다.
  - 들여쓴 하위 줄은 따라가지 않는다. v0.1-b에서 에디터 블록 단위로 옮기게 다시 본다.
- **캔버스 (2026-09-27):** 컬럼 스크롤을 없애고 `.ws`(뷰포트) > `.canvas`(translate + scale) > `.cols` 구조로 바꿨다. 빈 곳 끌기는 이동, 휠은 확대·축소다. 이동·확대 값은 React 상태가 아니라 ref에 두고 transform을 직접 바꾼다(아직 저장 안 함, v0.1-c).
  - 확대 상태에서도 맞도록 끌기, 크기 조절, FLIP 애니메이션은 화면 거리를 확대율(`scaleOf`)로 나눠 쓴다.
  - 화면 밖 경계: 스크롤 끝처럼 동작하고, 여유는 창 크기와 상관없이 40px이다. 넘으면 `resist`(30%)가 걸리고, 놓거나 휠을 멈추면 경계로 튕겨 돌아온다.
    - 바뀐 과정: 처음에는 내용이 거의 다 화면 밖으로 나가야 경계였다. 그랬더니 저항이 안 느껴졌다. 다음에는 반 패널(128×100px), 그다음에는 40px였다. 지금은 사용자 요청으로 컬럼 간격(12px)과 같다. `.cols` 안쪽 여백이 12px라서, 내용 상자가 화면 끝을 넘는 순간이 경계다. 마지막 컬럼의 오른쪽 여백은 계산에서 뺀다. 연결선을 켜면 컬럼 간격 34px에 맞춰 가로세로 모두 22px 여유를 더 준다(세로도 가로 간격 기준).
  - 관성: 놓기 직전 80ms 동안의 속도로 미끄러진다. 프레임마다 속도에 0.9를 곱하고, 경계를 넘으면 0.5를 곱한다. 멈추면 경계를 확인한다.
  - 패널 순서 바꾸기 기준: 처음에는 끄는 패널의 가운데로 판단했다. 끌 수 있는 범위가 형제 구간으로 막혀 있어서, 높이가 다른 패널끼리는 끝까지 끌어도 바뀌지 않았다. 지금은 패널 윗변(상단바를 잡는 곳) 이동 거리로, 옆 자리의 절반을 넘으면 바뀐다.
  - 사라진 기능: 하단 가로 스크롤바, 컬럼 세로 스크롤, 빈 배경 튕김 효과(캔버스 이동으로 대체).
- **패널 자유 끌기:** 패널은 어디로든 끌리지만 순서를 바꿀 수 있는 구간 밖으로 나간 거리는 30%만 따라온다. 놓으면 제자리나 새 자리로 들어간다.
- **(대체됨) 빈 배경 끌기 효과:** `.ws`에 translate를 걸어 패널 전체가 따라오게 한다. 끈 거리의 35%만 따라오고 최대 거리는 없다(처음엔 최대 120px로 막았는데 사용자가 저항은 더, 최대는 없이로 바꿨다). 놓으면 넘쳤다 돌아오는 곡선으로 0.5초 동안 되돌린다.
- **삭제와 되돌리기:** 삭제하면 노트, 서브트리, 링크를 뺀 위치, 열림 상태를 `state.deleted`에 보관한다. 되돌리기 알림이 사라질 때 버린다. v0.1-c에서 파일 삭제를 붙일 때도 이 시점에 확정하면 된다.
- **글꼴:** `@fontsource/ibm-plex-sans-kr` 패키지로 400, 600 굵기를 앱에 포함한다. CDN은 쓰지 않는다.
- **Tauri 템플릿 정리:** 쓰지 않는 opener 플러그인과 모바일용 빌드 산출물(staticlib, cdylib)을 뺐다.

## 미결 사항

개발을 막지는 않지만 확인이 필요한 것들이다.

1. **하위 노트 열리는 방향 설정.** 방향을 뒤집으면 최상위 노트가 오른쪽 끝에 붙고 하위 노트가 왼쪽으로 열리는 게 맞는지.
2. **계보 그라데이션 범위.** 선은 최저 10%로 정했다. 테두리는 세 칸 이상 떨어진 계보가 0%가 되는데 의도대로인지.
3. **기본 밝기.** 라이트, 다크, 시스템 설정 따르기 중 무엇을 기본으로 할지. 코드는 임시로 "시스템 설정 따르기"다.
4. **백업.** 변경 사항이 없으면 스냅샷을 건너뛸지.
5. **깨진 링크의 md 표기법.** 코드는 임시로 `[>](nodt:broken)`을 쓴다.
6. **앱 ID.** `app.nodt.desktop`으로 적용했다. 출시 전에 바꿀 수 있다.
7. **로고.**
8. **(v0.2)** 여러 모니터에서 플로팅 모드를 어느 모니터에 띄울지.

## 결정 이력

바뀐 결정과 그 이유다. 같은 논의를 반복하지 않기 위해 남긴다.

**이름과 기반**
- **이름:** Nodto에서 Nodt로 바꿨다.
- **저장 방식:** 처음 계획한 SQLite 대신 md 파일을 쓴다. 사용자가 파일을 직접 볼 수 있기 때문이다. 폴더 트리 대신 평평한 구조를 택했다. 부모 변경과 제목 변경이 쉽기 때문이다.
- **자동 저장:** 사용자는 처음에 "5분 주기 저장"을 원했다. 하지만 앱이 튕기면 최대 5분치가 날아가기 때문에, 실시간 저장(약 1초 debounce)에 5분부터 1달까지의 스냅샷 백업을 더하는 방식으로 합의했다.

**노트 모델**
- **링크:** "텍스트 일부를 링크로 바꾸는 방식"에서 "라벨 없는 기호 하나를 본문에 두는 방식"으로 바꿨다.
- **구조:** 그래프가 아니라 트리다. 부모는 하나뿐이다. 그래서 백링크 화면은 필요 없다. 화살표 방향은 자식의 열림 상태만 보면 된다.

**링크 조작**
- **삭제 방식 통일 (2026-09-27):** 본문에서 링크 기호를 지울 때도 확인 창 대신 되돌리기 알림을 쓴다. 우클릭 삭제와 방식을 하나로 맞추고, 글을 쓰는 흐름을 끊지 않기 위해서다.
- **깨진 링크 클릭 (2026-09-27):** 안내 알림 대신 칩 아래 드롭다운([새 노트로 만들기] / [삭제])을 띄운다. v0.1-a에서 이미 만들었다.
- 커서가 링크 뒤에 오면 드롭다운을 띄우는 안이 있었다. Enter가 줄바꿈과 충돌해서 폐기했고, `Ctrl+Enter`와 클릭만 남겼다.
- **복사·붙여넣기:** 부모가 하나뿐이라 `Ctrl+V`는 깨진 링크가 된다. 전체 복제는 `Ctrl+Shift+V`다. `Ctrl+Shift+V`는 보통 "서식 없이 붙여넣기"지만, Nodt는 서식이 적어서 그대로 쓰기로 했다.
- **이동:** 드래그로 옮기는 안을 제안했지만, 사용자가 `Ctrl+X` 박스 방식을 골랐다.

**패널 조작**
- **패널 이동 키:** `Tab`으로 모드를 전환하는 안은 리스트 들여쓰기와 겹쳐서 폐기했다. `Ctrl+방향키`는 사용자가 단어 이동으로 쓰고 있어서 제외했다. 결국 `Alt+방향키`와 `Ctrl+Tab` 패널이동모드로 정했다. 이름은 "줌아웃 모드"가 아니라 "패널이동모드"다.
- **최상위 노트 Esc:** 앱 종료가 아니라 경고만 띄운다. 실수로 앱이 꺼지는 것을 막기 위해서다.
- **패널 상단바 버튼 (2026-09-27, v0.1-a 화면을 보고)**
  - 처음에는 `[⇕ 하위 전체 펼치기/접기] [x 닫기]`였고, 최상위 노트에는 설정, 도움말, 앱 종료 `x`가 있었다.
  - 사용자가 창처럼 `[— 최소화] [x]` 두 개만 두기로 했다.
    - 설정과 도움말은 프로그램 상단바로 옮겼다. 그래서 자체 상단바를 v0.1-d에서 앞당겼다.
    - 최상위 노트의 앱 종료 `x`는 없앴다. 앱 종료는 프로그램 상단바의 닫기 버튼으로 한다.
  - `x`를 잠깐 노트 삭제로 바꿨다. 써 보니 닫기가 더 자연스러워서 `x`는 다시 닫기로 돌렸다.
  - 삭제는 상단바 우클릭 메뉴로 옮겼다. 본문 우클릭은 v0.1-b 에디터 메뉴와 겹쳐서 피했다. 확인 창 대신 되돌리기 알림(8초, `Ctrl+Z`)을 띄운다. 갈 곳이 없던 하위 전체 펼치기/접기도 이 메뉴에 넣었다.
  - 최소화는 "collapse처럼": 제목줄만 남기고 접히고 하위 패널도 숨는다. 복원하면 전에 열려 있던 그대로 돌아온다.
  - 최상위 노트 `Esc` 경고는 이제 프로그램 상단바의 닫기 버튼을 빛낸다.
- **링크 화살표 (2026-09-27):** 처음에는 열림 →, 닫힘 ←였다. 사용자가 반대로 바꿨다. 닫힌 링크 →는 "누르면 오른쪽으로 들어간다", 열린 링크 ←는 "누르면 닫힌다"로 읽힌다.

**관계 표시**
- 네 가지를 비교했다: 없음, 선, 선 + 계보 강조, 깊이 그라데이션.
- 사용자의 규칙으로 확정했다.
  - 선택한 패널 기준으로 계보(위로만 또는 아래로만)를 따라 40%p씩 옅어지는 상단바 그라데이션.
  - 계보 밖은 0%.
  - 선은 옵션.
- 선택한 패널 상단바의 최대 진하기는 목업의 강조색 30%였다. v0.1-a 화면을 본 사용자가 더 진하게 해 달라고 해서 50%로 올렸다 (2026-09-27).
- 같은 날 옅어지는 폭도 40%p에서 30%p로 바꿨다: 100 → 70 → 40 → 10 → 0%. 세 칸 떨어진 계보까지 색이 남는다.
- 패널 크기는 처음에 화면 비율(너비 1/5, 높이 1/3)이었다. 창 크기를 바꿀 때 패널까지 변하는 게 싫다는 피드백으로 고정 px로 바꿨다.
- 이어서 상단바 배경 칠하기를 **패널 맨 위 굵은 선**으로 바꿨다. 처음 4px였고 사용자 요청으로 8px로 키웠다. 상단바 색과 링크 색이 달라 보이는 문제 때문이다. 링크 색을 옅게 하거나 상단바를 강조색 100%로 칠하는 안도 있었다. 선 방식은 100%가 강조색 그대로라 링크와 정확히 같은 색이 되고, 상단바는 조용하게 남는다.
- 선 최저 밝기를 10%로 고정했다. 계보 밖 선이 0%(패널색)면 흰 띠로 보여 상단바가 비고 높아 보였기 때문이다. 같은 이유로 패널 상단바 위아래 여백을 줄였다(높이 44px → 37px).
- 링크 칩 아이콘을 화살표(→ ←)에서 꺾쇠(> <)로 바꿨다 (2026-09-27). 꺾쇠가 작아져서 칩도 24×17 알약에서 17px 원으로 바꿨다. 깨진 링크는 끊긴 화살표와 빨간 점선에서 x와 빨간 실선 원으로 바꿨다.
- 컬럼 너비 손잡이를 컬럼 사이 틈에서 패널 오른쪽 가장자리로 옮겼다. 어느 패널을 끌어도 컬럼 전체가 같이 바뀐다.
- 설정 아이콘이 해처럼 보인다는 피드백을 받았다. 떨어진 막대 8개 대신 톱니가 몸통에 붙은 톱니바퀴(Lucide settings, ISC)로 바꾸고, 프로그램 상단바 아이콘을 16px로 키웠다.
- 링크 칩도 반전했다. 닫힌 링크가 채운 알약, 열린 링크가 테두리 알약이다.
- 기각한 안
  - 매 칸 직전 값의 60%로 곱해 줄이는 방식
  - 형제까지 거리로 세는 방식
  - 컬럼 깊이 기준 그라데이션
