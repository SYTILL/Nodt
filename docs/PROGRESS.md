## 개발 명령과 테스트

- `npm run tauri dev`: 앱 창으로 실행한다. 데이터는 `문서\Nodt`에 저장된다.
- `npm run dev`: 브라우저에서 본다(http://localhost:1420). 파일 대신 localStorage에 저장한다.
  - 주소에 `?sample`을 붙이면 저장하지 않는 샘플 노트로 뜬다. 자동 테스트가 이 모드를 쓴다.
- `NODT_DATA_DIR`, `NODT_CONFIG_DIR` 환경변수로 데이터 폴더와 설정 폴더를 바꿀 수 있다. 실제 노트를 건드리지 않고 테스트할 때 쓴다.
- `cargo test --lib` (src-tauri): 파일 저장, ID 제한, 백업 순환 테스트.
- 화면 자동 테스트(puppeteer)는 세션 임시 폴더에서 돌렸다. 저장소에는 넣지 않았다.

## 구현 방식

### 구조
| 경로 | 내용 |
|---|---|
| `src/model/notes.ts` | 노트 모델, 문서(JSON) 안 링크 찾기·빼기·넣기·옮기기, 트리 계산 |
| `src/model/markdown.ts` | md ↔ 에디터 문서 변환 |
| `src/state/store.ts` | 상태와 동작(reducer). 열림, 선택, 삭제·되돌리기, 순서 바꾸기, 설정 |
| `src/editor/` | Tiptap 확장: 링크 노드, 키, `/` 메뉴, 클립보드와 잘라내기 박스 |
| `src/ui/` | 화면: Workspace(캔버스), Panel, NoteEditor, 메뉴, 설정·도움말, 애니메이션 |
| `src/storage/` | 저장: backend(Tauri 명령 / localStorage), 노트 파일 형식, 불러오기와 자동 저장 |
| `src-tauri/src/storage.rs` | 파일 읽기·쓰기(원자적), 백업 스냅샷 |
| `src-tauri/src/lib.rs` | Tauri 명령, 창 위치 복원, Mica, 플러그인(dialog) |

### 에디터와 데이터 (v0.1-b)
- **본문은 앱 안에서 에디터 문서(Tiptap JSON)로 들고 있다.** md는 파일을 읽고 쓸 때만 변환한다. 에디터가 곧 원본이라 빈 줄, 커서 자리가 흐트러지지 않는다.
- 에디터가 바뀌면 `editDoc`으로 상태에 올린다. 메뉴 삭제, 순서 바꾸기처럼 밖에서 문서가 바뀌면 에디터가 새 문서를 받아 커서 자리를 지키며 바꾼다(`NoteEditor.tsx`). 이 동기화는 React 렌더가 끝난 뒤(microtask)에 한다.
- **링크를 지우면**(Backspace, 선택 삭제) `editDoc`이 사라진 링크를 보고 그 노트와 하위 노트를 삭제 대기로 옮긴다. 되돌리기 알림이 떠 있는 동안 `Ctrl+Z`나 알림 버튼으로 되돌린다. 에디터 자체의 되돌리기로 링크가 다시 생겨도 노트가 되살아난다.
- **잘라내기 이동:** 붙일 때 원래 자리에서 빼는 트랜잭션에 `nodtKeep` 표시를 달아 삭제로 보지 않는다. 에디터마다 스키마 객체가 따로라서, 다른 에디터의 조각은 받는 쪽 스키마로 다시 만들어 넣는다(이걸 빠뜨리면 조각이 조용히 버려진다).
- **Esc는 앱의 capture 단계에서 처리한다.** ProseMirror는 Enter와 Esc를 늘 "처리함"으로 표시해서, bubble 단계에서는 에디터가 썼는지 알 수 없다. 슬래시 메뉴가 떠 있을 때만 에디터에 넘긴다.
- **초점:** 키보드로 패널을 옮기면 `focus` 요청을 보내 그 패널 에디터의 마지막 커서 자리로 간다. 새 노트는 제목으로 간다.

### 저장 (v0.1-c)
- 자동 저장(`Saver`)은 상태가 바뀔 때마다 1초 타이머를 다시 건다. 최상위 노트에서 닿는 노트 중 바뀐 것만 직렬화해서, 파일 내용이 다를 때만 쓴다.
- 삭제된 노트의 파일은 상태에서 사라지고 되돌리기를 기다리지 않을 때 지운다. 앱을 닫을 때는 기다리던 삭제도 확정한다.
- 창을 닫을 때(`onCloseRequested`) 창 위치를 적고 저장을 마친 뒤 창을 없앤다.
- 창 위치 복원은 Rust `setup`에서 창을 보이기 전에 한다. 테두리 없는 창은 첫 `set_size` 때만 안쪽 크기가 제목 표시줄 높이(약 30px)만큼 어긋나서, 어긋났으면 한 번 더 넣는다.
- 백업은 프론트엔드가 1분마다 `backup_tick`을 부르고, Rust가 주기가 된 단계만 만든다. 노트 내용 해시(FNV-1a)가 마지막 스냅샷과 같으면 건너뛴다.

### 창 (v0.1-d)
- 창 모드와 전역 단축키는 없앴다(결정 이력 참고). global-shortcut 플러그인도 뗐다.
- Mica: 창은 `transparent: true`로 만들고, 프론트엔드가 밝기에 맞춰 `set_mica(dark)`를 부른다. Rust가 Windows 빌드 22000 이상이면 `MicaDark`/`MicaLight`를 깔고 true를 돌려준다. true일 때만 `html.mica`를 붙여 배경을 반투명하게 그린다.
- 백업에서 되돌리기: `list_backups`, `restore_backup`(storage.rs). 되돌리는 동안 `Saver.stop()`으로 저장을 멈추고, 성공하면 새로 불러오고 실패하면 `resume()`.

### 화면 (v0.1-a와 피드백)
- **패널 영역 분리:** `Workspace` 컴포넌트가 패널 영역이고 창과 분리돼 있다(스펙 8.2).
- **여닫기 애니메이션:** `src/ui/transition.ts`의 FLIP 방식이다. 바뀌기 전 패널 위치를 재고, 상태를 바꾸고, 실제 패널을 Web Animations로 옛 자리에서 새 자리로 옮긴다. 닫힌 패널은 DOM에서 빠진 요소를 `#exit-layer`에 잠깐 올려 사라지게 한다.
  - 처음에는 View Transitions API를 썼다. 전환 중에는 패널이 클릭을 받지 못해서 FLIP으로 바꿨다.
  - 애니메이션 동안 `nodt:relayout` 신호를 매 프레임 보내고, `Workspace`는 받자마자 연결선을 다시 그린다.
- **캔버스:** `.ws`(뷰포트) > `.canvas`(translate + scale) > `.cols` 구조다. 빈 곳 끌기는 이동(관성, 경계 저항), 휠은 확대·축소다. 이동·확대 값은 ref에 두고 transform을 직접 바꾸며, 멈추면 상태에 넣어 저장한다.
  - 확대 상태에서도 맞도록 끌기, 크기 조절, 애니메이션은 화면 거리를 확대율(`scaleOf`)로 나눠 쓴다.
  - 화면 밖 경계는 스크롤 끝처럼 동작한다. 가장자리 패널과 화면 끝 사이가 컬럼 간격(12px, 연결선을 켜면 34px)을 넘으면 30%만 따라온다.
  - 관성: 놓기 직전 80ms 동안의 속도로 미끄러진다. 프레임마다 속도에 0.9를 곱하고, 경계를 넘으면 0.5를 곱한다.
- **패널 끌어서 순서 바꾸기:** `src/ui/panelDrag.ts`. 놓으면 `reorder`로 부모 본문에서 링크가 든 목록 항목(하위 항목 포함)이나 블록을 통째로 옮긴다. 한 블록에 다른 링크가 같이 있으면 링크 기호만 옮긴다.
  - 순서는 형제끼리만 바뀐다. 사촌 사이 이동은 부모 변경이라 `Ctrl+X` 방식에 맡긴다.
  - 기준은 패널 윗변(상단바를 잡는 곳) 이동 거리다. 옆 자리의 절반을 넘으면 바뀐다.
- **글꼴:** `@fontsource/ibm-plex-sans-kr` 패키지로 400, 600 굵기를 앱에 포함한다. CDN은 쓰지 않는다.

## 결정 이력

바뀐 결정과 그 이유다. 같은 논의를 반복하지 않기 위해 남긴다.

### 2026-09-27 (v0.1 확인 1차)
- 기본 밝기 "시스템 설정 따르기", 바뀐 게 없으면 백업 건너뛰기, 깨진 링크 표기 `[>](nodt:broken)`를 확정했다.
- 하위 노트 열리는 방향 설정은 만들지 않기로 했다.
- 처음 켤 때 짧은 안내 대신 파트별 하위 노트가 있는 사용법 노트를 보여준다. 전체 구조가 어떻게 쓰이는지 한눈에 보이게 하려는 것이다. 한 파트만 펼치고 나머지는 최소화한다.
- 설정 왼쪽에 초기화 버튼을 두고, 누르면 반드시 확인 창을 띄운다. 지우기 전 노트는 `backups\reset`에 남긴다.
- 초기화는 두 가지다: 사용법 노트로(설정 유지), 완전 초기화(빈 화면, 설정 기본값).
- **최상위 노트를 여러 개** 둘 수 있게 했다. 첫 컬럼에 쌓이고, 삭제와 순서 바꾸기가 된다. 하나도 없으면 빈 화면에 안내만 보인다.
- 빈 곳을 누르면 선택이 풀린다. 선택이 없을 때 `Ctrl+N`은 새 최상위 노트, 선택이 있으면 하위 노트 링크다. 새 노트 링크 키는 `Ctrl+.`에서 `Ctrl+N`으로 바꿨다.
- 제목에서(또는 패널만 선택하고) `Ctrl+N`을 누르면 본문 끝 새 줄에 링크를 붙인다. 커서를 본문 맨 앞으로 옮겨 넣으면 기존 첫 줄 앞에 링크가 끼기 때문이다. 본문이 목록으로 끝나면 목록 항목으로 붙인다.
- 초기화 확인 창은 완전 초기화를 위에 두고 기본으로 고른다. 설정은 앱 전체 것이라 완전 초기화도 설정은 건드리지 않는다.
- 창 모드(항상 위, 전역 단축키 `Ctrl+Alt+N`)를 없앴다. 늘 일반 창이다. global-shortcut 플러그인도 뗐다.
- 연결선 기본값을 켜기로 바꾸고 설정에서 켜기를 앞에 둔다.
- 하위 노트는 새로 열렸을 때 안내 글(제목 없음, 내용 · / 로 명령)을 보이지 않는다. 최상위 노트만 보인다.
- **노트에 들어가는 길은 이 프로그램 하나다.** 전용 확장자(.nodt), 열기, 다른 이름으로 저장, 노트북 여러 개는 만들지 않는다. 저장 방식은 지금처럼 노트마다 md 파일이다(프로그램으로만 보니 겉으로는 차이가 없고, 노트 하나만 다시 쓰고 원자적으로 쓰는 지금 방식이 더 안전하다). 데이터 폴더 바꾸기는 OneDrive 같은 곳으로 옮기는 용도로 남긴다.
- 그래서 백업을 되돌리는 것도 프로그램 안에서 할 수 있어야 한다. 설정에 "백업에서 되돌리기"를 넣는다(Rust 빌드가 필요해 디스크 정리 뒤에).
- Mica를 넣는다. 흐림을 실시간으로 계산하지 않아 부담이 거의 없다. 패널은 글이 잘 읽히게 불투명하게 둔다.
- 사용법 노트의 예제는 누구나 쓸 법한 일상 내용(이번 주 할 일, 독서 기록)으로 한다.
- **영어판을 메인으로 한다.** 화면 글은 모두 영어가 기본이고, 설정에 언어(English / 한국어)를 둔다. 글은 `src/i18n.ts` 한 곳에 두 언어로 모았다. 사용법 노트도 두 언어로 만들었다. 문서와 코드 주석은 한국어 그대로다.
- **되돌리기를 앱 전체 하나로 했다.** 노트마다 따로인 글 되돌리기, 닫은 패널 다시 열기, 삭제 알림 되돌리기가 따로 놀아서 섞어 쓰면 기대와 다르게 움직였다(예: 없던 일로 한 새 노트를 Ctrl+Z 하면 깨진 링크가 생김). 이제 노트 구조의 모든 변화를 한 줄로 기록한다(SPEC 5.1). Tiptap 자체 되돌리기(undoRedo)는 껐다.
- **Esc는 어디서든 선택만 푼다.** 패널 닫기는 Ctrl+W, x 버튼, 링크로 한다. 최상위 노트 Esc 경고는 없앴다.
- 제목은 상단바처럼 동작하고 두 번 눌러야 고친다. 제목을 눌러 패널을 고르거나 끌려다가 입력칸에 들어가 버리는 일을 막기 위해서다.
- `Ctrl+W`는 선택한 패널을 닫는다. 최상위 노트는 닫을 수 없으므로 최소화하고, 다시 누르면 복원한다(키보드만으로 되돌릴 수 있게).

**이름과 기반**
- **이름:** Nodto에서 Nodt로 바꿨다.
- **저장 방식:** 처음 계획한 SQLite 대신 md 파일을 쓴다. 사용자가 파일을 직접 볼 수 있기 때문이다. 폴더 트리 대신 평평한 구조를 택했다. 부모 변경과 제목 변경이 쉽기 때문이다.
- **자동 저장:** 사용자는 처음에 "5분 주기 저장"을 원했다. 하지만 앱이 튕기면 최대 5분치가 날아가기 때문에, 실시간 저장(약 1초 debounce)에 5분부터 1달까지의 스냅샷 백업을 더하는 방식으로 합의했다.

**노트 모델**
- **링크:** "텍스트 일부를 링크로 바꾸는 방식"에서 "라벨 없는 기호 하나를 본문에 두는 방식"으로 바꿨다.
- **구조:** 그래프가 아니라 트리다. 부모는 하나뿐이다. 그래서 백링크 화면은 필요 없다. 화살표 방향은 자식의 열림 상태만 보면 된다.

**링크 조작**
- **본문 데이터 (v0.1-b):** v0.1-a는 본문을 md 문자열로 들고 읽기 전용으로 그렸다. 에디터를 붙이면서 앱 안의 원본을 에디터 문서(JSON)로 바꿨다. md로 매번 오가면 빈 줄과 커서 자리가 흐트러지기 때문이다.
- **삭제 방식 통일 (2026-09-27):** 본문에서 링크 기호를 지울 때도 확인 창 대신 되돌리기 알림을 쓴다. 우클릭 삭제와 방식을 하나로 맞추고, 글을 쓰는 흐름을 끊지 않기 위해서다.
- **깨진 링크 클릭 (2026-09-27):** 안내 알림 대신 칩 아래 드롭다운([새 노트로 만들기] / [삭제])을 띄운다. v0.1-a에서 이미 만들었다.
- 커서가 링크 뒤에 오면 드롭다운을 띄우는 안이 있었다. Enter가 줄바꿈과 충돌해서 폐기했고, `Ctrl+Enter`와 클릭만 남겼다.
- **복사·붙여넣기:** 부모가 하나뿐이라 `Ctrl+V`는 깨진 링크가 된다. 전체 복제는 `Ctrl+Shift+V`다. `Ctrl+Shift+V`는 보통 "서식 없이 붙여넣기"지만, Nodt는 서식이 적어서 그대로 쓰기로 했다.
- **이동:** 드래그로 옮기는 안을 제안했지만, 사용자가 `Ctrl+X` 박스 방식을 골랐다.

**패널 조작**
- **패널 이동 키:** `Tab`으로 모드를 전환하는 안은 리스트 들여쓰기와 겹쳐서 폐기했다. `Ctrl+방향키`는 사용자가 단어 이동으로 쓰고 있어서 제외했다. 결국 `Alt+방향키`와 `Ctrl+Tab` 패널이동모드로 정했다. 이름은 "줌아웃 모드"가 아니라 "패널이동모드"다.
- **최상위 노트 Esc:** 앱 종료가 아니라 경고만 띄운다. 실수로 앱이 꺼지는 것을 막기 위해서다.
- **패널 상단바 버튼 (2026-09-27, v0.1-a 화면을 보고)**
  - 처음에는 `[⇕ 하위 전체 펼치기/접기] [x 닫기]`였고, 최상위 노트에는 설정, 도움말, 앱 종료 `x`가 있었다.
  - 사용자가 창처럼 `[— 최소화] [x]` 두 개만 두기로 했다.
    - 설정과 도움말은 프로그램 상단바로 옮겼다. 그래서 자체 상단바를 v0.1-d에서 앞당겼다.
    - 최상위 노트의 앱 종료 `x`는 없앴다. 앱 종료는 프로그램 상단바의 닫기 버튼으로 한다.
  - `x`를 잠깐 노트 삭제로 바꿨다. 써 보니 닫기가 더 자연스러워서 `x`는 다시 닫기로 돌렸다.
  - 삭제는 상단바 우클릭 메뉴로 옮겼다. 본문 우클릭은 v0.1-b 에디터 메뉴와 겹쳐서 피했다. 확인 창 대신 되돌리기 알림(8초, `Ctrl+Z`)을 띄운다. 갈 곳이 없던 하위 전체 펼치기/접기도 이 메뉴에 넣었다.
  - 최소화는 "collapse처럼": 제목줄만 남기고 접히고 하위 패널도 숨는다. 복원하면 전에 열려 있던 그대로 돌아온다.
  - 최상위 노트 `Esc` 경고는 이제 프로그램 상단바의 닫기 버튼을 빛낸다.
- **링크 화살표 (2026-09-27):** 처음에는 열림 →, 닫힘 ←였다. 사용자가 반대로 바꿨다. 닫힌 링크 →는 "누르면 오른쪽으로 들어간다", 열린 링크 ←는 "누르면 닫힌다"로 읽힌다.

**관계 표시**
- 네 가지를 비교했다: 없음, 선, 선 + 계보 강조, 깊이 그라데이션.
- 사용자의 규칙으로 확정했다.
  - 선택한 패널 기준으로 계보(위로만 또는 아래로만)를 따라 40%p씩 옅어지는 상단바 그라데이션.
  - 계보 밖은 0%.
  - 선은 옵션.
- 선택한 패널 상단바의 최대 진하기는 목업의 강조색 30%였다. v0.1-a 화면을 본 사용자가 더 진하게 해 달라고 해서 50%로 올렸다 (2026-09-27).
- 같은 날 옅어지는 폭도 40%p에서 30%p로 바꿨다: 100 → 70 → 40 → 10 → 0%. 세 칸 떨어진 계보까지 색이 남는다.
- 패널 크기는 처음에 화면 비율(너비 1/5, 높이 1/3)이었다. 창 크기를 바꿀 때 패널까지 변하는 게 싫다는 피드백으로 고정 px로 바꿨다.
- 이어서 상단바 배경 칠하기를 **패널 맨 위 굵은 선**으로 바꿨다. 처음 4px였고 사용자 요청으로 8px로 키웠다. 상단바 색과 링크 색이 달라 보이는 문제 때문이다. 링크 색을 옅게 하거나 상단바를 강조색 100%로 칠하는 안도 있었다. 선 방식은 100%가 강조색 그대로라 링크와 정확히 같은 색이 되고, 상단바는 조용하게 남는다.
- 선 최저 밝기를 10%로 고정했다. 계보 밖 선이 0%(패널색)면 흰 띠로 보여 상단바가 비고 높아 보였기 때문이다. 같은 이유로 패널 상단바 위아래 여백을 줄였다(높이 44px → 37px).
- 링크 칩 아이콘을 화살표(→ ←)에서 꺾쇠(> <)로 바꿨다 (2026-09-27). 꺾쇠가 작아져서 칩도 24×17 알약에서 17px 원으로 바꿨다. 깨진 링크는 끊긴 화살표와 빨간 점선에서 x와 빨간 실선 원으로 바꿨다.
- 컬럼 너비 손잡이를 컬럼 사이 틈에서 패널 오른쪽 가장자리로 옮겼다. 어느 패널을 끌어도 컬럼 전체가 같이 바뀐다.
- 설정 아이콘이 해처럼 보인다는 피드백을 받았다. 떨어진 막대 8개 대신 톱니가 몸통에 붙은 톱니바퀴(Lucide settings, ISC)로 바꾸고, 프로그램 상단바 아이콘을 16px로 키웠다.
- 링크 칩도 반전했다. 닫힌 링크가 채운 알약, 열린 링크가 테두리 알약이다.
- 기각한 안
  - 매 칸 직전 값의 60%로 곱해 줄이는 방식
  - 형제까지 거리로 세는 방식
  - 컬럼 깊이 기준 그라데이션
